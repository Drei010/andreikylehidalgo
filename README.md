# Andrei Kyle Hidalgo - Portfolio

My web portfolio that I used to get internships when I was in my junior year of college. Back then there was no AI and I was really interested in animated websites, so I had to master HTML and CSS to create this. 

You can check it out here
https://drei010.github.io/andreikylehidalgo/

## ✨ Features

- Smooth scroll animations and interactive elements
- Responsive design (desktop, tablet, mobile)
- Project showcase with detailed descriptions
- Skills section (Frontend & Backend)
- Downloadable resume and contact information

## 🛠️ Built With

- HTML5 & CSS3
- JavaScript (GSAP for animations)
- Font Awesome icons

## 📚 Portfolio Sections

- **About** - Background and interests
- **Skills** - Frontend (HTML, CSS, JavaScript) & Backend (C#, Python, Java, SQL)
- **Projects** - Midnight Coffee, Handy Magic, Delivery Expenses App, CloudComplexitech
- **Contact** - Email, phone, and social links
